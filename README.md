# Satış reportu | Power BI

Bu interaktiv Power BI hesabatı 2022 və 2023-cü illərin satışlarını region və məhsul üzrə təhlil etmək üçün hazırlanıb. Hesabatda ümumi satış məbləğini görmək, regionları müqayisə etmək və seçilmiş məhsul üzrə satış təfərrüatlarına baxmaq mümkündür.

## Hesabatda nələr var?

| Vizual | Nə göstərir? |
| --- | --- |
| Ümumi satış kartı | Cari seçimlər üzrə cəmi satış məbləğini göstərir. |
| Üfüqi çubuq qrafiki | Satış məbləğini regionlar üzrə müqayisə edir. |
| Dairəvi diaqram | Göstərilən məhsulların satış məbləğindəki payını göstərir. |
| Xətti qrafik | Məhsullar üzrə satış məbləğlərini müqayisə edir. |
| Satış cədvəli | Şəhər, kateqoriya, müştəri nömrəsi, il, məhsul və satış məbləği üzrə detalları göstərir. |

## İstifadə qaydası

1. Hesabatın `.pbix` faylını **Power BI Desktop** proqramında açın.
2. İl filtrindən **2022** və ya **2023** seçin.
3. Məhsul siyahısından maraqlandığınız məhsulu seçin və qrafiklərlə cədvəldə nəticələrə baxın.
